# Formal Accommodation Request Letter
## Attachment to HHS-995 (Written Confirmation of Request for Accommodation)
 
*For Review and Revision Before Submission*
*Written in the employee's own voice — this is the employee's formal statement of her own request and should remain in first person regardless of whether a representative is assisting in preparing it.*
 
**Instructions:** This letter is submitted alongside HHS-995 as the attachment referenced in Item 10 ("Reason for Request"). It should not be summarized or compressed into the HHS-995 form itself. Item 9 of HHS-995 should still name the specific accommodation(s) directly on the form; this letter provides the full statement, priority order, and reasoning behind that request. Bracketed fields [like this] require case-specific information.

Dear Reasonable Accommodation Coordinator,
 
I am submitting this letter as an attachment to my Written Confirmation of Request for Accommodation (HHS-995), to provide the complete basis for my request. This letter should be read together with that form and with any medical documentation submitted separately.
 
---
 
### I. Background and History
 
[Provide relevant background: how long the employee has held the position, general job history, and — where applicable — history of any prior accommodation, including whether it was formal or informal, how long it was in place, and its documented outcome (e.g., performance ratings, absence of performance concerns). If the position description or essential functions have not changed since any prior accommodation period, state that explicitly, as this supports the argument that a similar accommodation would not now constitute undue hardship.]
 
---
 
### II. Functional Limitations and Workplace Barriers
 
[Describe, in functional terms only and without diagnostic labels unless already elected, the limitations that affect the employee's ability to perform her job. Note whether limitations are constant or episodic, and if episodic, describe frequency, duration, and severity during acute periods. Describe the specific workplace barriers — environmental, physical, or procedural — that interact with these limitations.]
 
---
 
### III. Essential Functions Affected
 
[Identify the essential functions of the position, as reflected in the position description or PMAP, that are affected by the functional limitations described above. Describe concretely how each function is affected — for example, sustaining attention, communicating in real time, sitting for extended periods, or completing travel.]
 
---
 
### IV. Accommodations Requested
 
[List the specific accommodation(s) being requested, in priority order if more than one. Each should be named specifically and match what is entered in Item 9 of HHS-995 — e.g., full-time telework, a Maxiflex schedule, specific travel modifications. Avoid general language such as "flexibility" or "reduced demands." For each accommodation, briefly note the nexus to the functional limitation(s) and essential function(s) identified above.]
 
---
 
### V. Alternative Accommodations
 
**If the agency has already identified or proposed alternatives:** Address each by name:
- Describe what functional barrier the alternative does and does not address
- Characterize the alternative as less effective than the requested accommodation, rather than wholly ineffective, unless a stronger characterization is factually supportable
- Close with a summary statement that the alternatives, individually and collectively, do not fully address the functional limitations described above
**If the agency has not yet identified alternatives:** Do not state only that none have been proposed. Based on the functional limitations described in Section II, identify the accommodations most likely to be proposed — informed by JAN (Job Accommodation Network) guidance for these limitation types, particularly where the agency is known to rely on JAN-sourced suggestions for non-telework alternatives — and address each preemptively using the same framework above, clearly labeled as anticipated rather than agency-proposed (e.g., "Should the agency propose [X], this would not fully address..."). Confirm the anticipated list with the employee before finalizing this section.
 
---
 
### VI. Medical Documentation
 
[Reference the medical documentation being submitted in support of this request — identify each provider by role (e.g., treating neurologist, treating orthopedist) without including diagnosis information here, state that the documentation addresses the nature, severity, duration, and extent of the limitations described above, and note that it should be read together with this letter.]
 
---
 
### VII. Requested Duration
 
[State whether a permanent and indefinite accommodation is being requested, consistent with any medical documentation submitted. If supporting medical documentation recommends permanence, reference that here. If duration is expected to be reassessed at some interval, state the proposed interval.]
 
---
 
### VIII. Closing
 
[Summarize the request, reiterate availability to participate in the interactive process, and state the consequences if the accommodation is not provided — described concretely in terms of functional and performance impact, grounded in documented history where possible rather than speculation.]
 
I am available to discuss this request further and to participate in the interactive process at your convenience. Please contact me at [phone / email] with any questions.
